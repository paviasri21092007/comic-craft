# ComicCraft

ComicCraft is an AI-powered comic story creator.

## Features

- AI story generation
- Five comic panels
- Character customization
- Setting customization
- Story tone customization
- Art style customization
- Gemini integration
- Stable Diffusion integration
- Comic preview
- PDF export
- FastAPI REST API
- Jinja2 frontend
- Swagger API documentation
